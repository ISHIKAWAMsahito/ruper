# ASO案1：実用ルーペ特化

## アプリ名（30文字以内）
```
ルーペ拡大鏡 - 広告なし高画質ズーム
```
（19文字）

## 簡単な説明（80文字以内）
```
全画面広告ゼロ。説明書も成分表も爆速起動でくっきり拡大。静止ズームで手ブレなし。
```
（39文字）

## 詳しい説明

### 小さな文字を、広告に邪魔されずにくっきり拡大。

**ルーペ拡大鏡**は、起動して1秒でスマホが高性能ルーペに変わる、シンプル＆軽量の拡大鏡アプリです。
**操作中に全画面広告が表示されることは一切ありません。** 広告は画面の一番下の小さなバナーだけです。

#### こんなときに
- 家電や機器の**説明書**の細かい文字
- **薬の成分表**・用法用量・添付文書
- 食品パッケージの**原材料表示**・賞味期限
- **電子基板**の部品番号やはんだ付けの確認
- 領収書・レシートの薄れた印字
- 契約書や地図、新聞の小さな文字

#### 3つのこだわり
**1. 爆速起動**
スプラッシュ画面も広告待ちもありません。権限を許可すれば1秒以内にカメラが映ります。

**2. ブレない「静止ズーム」**
画面下の一時停止ボタンを押すと高解像度の静止画で固定。ピンチ操作で最大10倍まで拡大し、ドラッグで好きな場所をじっくり観察できます。手がプルプル震えても大丈夫。

**3. 見やすさを高めるフィルター**
- **通常カラー**
- **ハイコントラスト白黒**：薄い印字やレシートの文字を浮き立たせます
- **ネガ反転**：白黒を反転してコントラストを補助します

#### 使いやすさ
- ピンチ操作＆**片手で動かせる縦スライダー**で、1.0倍〜端末の最大倍率まで滑らかにズーム
- ワンタップで**LEDライト**を点灯。暗い場所の細かい文字もしっかり照らします
- 大きなボタンと分かりやすい画面で、**シニアの方**にも迷わず使えます
- 前回のズーム倍率やフィルター設定を自動で記憶

#### プライバシーも安心
カメラ映像はすべて端末内だけで処理され、外部に送信・保存されません。

#### 広告について
画面最下部のバナー広告のみ表示されます。**買い切り（1回のみのお支払い）で広告を非表示**にできます。サブスクリプションはありません。

その他、インカメラによる手鏡モードも搭載しています。
