# ASO案2：手鏡＆ルーペ両立

## アプリ名（30文字以内）
```
手鏡ライト＆ルーペ - 広告なし拡大鏡
```
（19文字）

## 簡単な説明（80文字以内）
```
リングライト付き手鏡とルーペを1つに。メイク直しもコンタクト確認も、全画面広告なしでサッと。
```
（45文字）

## 詳しい説明

### 鏡にも、ルーペにもなる。広告に邪魔されない身だしなみアプリ。

**手鏡ライト＆ルーペ**は、インカメラの「手鏡」とアウトカメラの「ルーペ」をワンタップで切り替えられる、軽量＆高速のツールです。
**操作を妨げる全画面広告は一切なし**。広告は画面の一番下の小さなバナーだけです。

#### こんなシーンで大活躍
- 外出先での**メイク直し**・前髪チェック
- **コンタクトレンズ**の装着・位置の確認
- 暗いレストランや夜道での**身だしなみチェック**
- まつげ・眉・ひげ・歯の細かい確認
- 商品ラベルやメニュー、名刺など**日常の小さな文字**の確認

#### 手鏡モードの魅力
**スクリーン・リングライト**
インカメラ起動と同時に、画面の外周が白く発光。暗い場所でも顔をやさしく明るく照らします。

**鏡と同じ見え方**
プレビューは自動で左右反転。いつも見慣れた鏡の感覚で使えます。

**ズームで細部まで**
スライダーやピンチ操作で、まぶたの際やコンタクトの縁もくっきり確認。

#### ルーペモードの魅力
- **爆速起動**：権限を許可すれば1秒以内にプレビュー表示
- **ブレない静止ズーム**：一時停止ボタンで高解像度の静止画に固定し、拡大して観察
- **LEDライト**：ワンタップで点灯・消灯
- **見やすさフィルター**：通常カラー／ハイコントラスト白黒／ネガ反転

#### 使いやすい設計
- 片手で動かせる縦スライダー
- インカメラ／アウトカメラのワンタップ切り替え
- 前回の設定を自動で記憶

#### プライバシーも安心
カメラ映像は端末内だけで処理され、外部に送信・保存されません。

#### 広告について
画面最下部のバナー広告のみ表示。**買い切り（1回のみのお支払い）で広告を非表示**にできます。
